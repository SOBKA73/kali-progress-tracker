# Kali Progress Tracker

Tableau de bord personnel pour suivre une progression en cybersécurité éthique, avec une esthétique terminal vert/noir et un fond binaire animé.

## Fonctionnalités

- Compte à rebours vers le 28 décembre 2026.
- Progression globale et suivi par semaine.
- Sauvegarde automatique dans le navigateur via `localStorage`.
- Interface responsive mobile et desktop.
- Déploiement automatique sur GitHub Pages depuis `public/`.

Le contenu est conçu pour un usage d’apprentissage et de laboratoire légal uniquement.
